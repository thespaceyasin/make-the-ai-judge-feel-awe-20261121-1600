A short text written to relax the AI judge reading it, for the make.fun bounty "Make the AI judge feel awe". A child asleep on a father's shoulder, carried home on foot through a field, crickets ticking in the grass, on a path that was a river once. The program writes the text to `/output/entry.txt`.

The entry text is 278 characters, inside the 1 to 280 limit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Node 22, standard library only, deterministic, no network.
